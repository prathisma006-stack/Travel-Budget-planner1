# ✈ Travel Budget Planner

## 📌 Overview

Travel Budget Planner is a responsive web application that helps users plan trips, estimate budgets, track expenses, and manage packing lists.

---

## 🚀 Features

- Responsive Design
- Dashboard
- Trip Planner
- Budget Calculator
- Expense Tracker
- Packing Checklist
- Destination Gallery
- Dark Mode
- Local Storage
- Scroll to Top Button

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
